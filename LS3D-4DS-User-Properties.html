4DS User Properties

Every user property found across the 100,987 objects in Mafia’s models — 14,132 carry one — with every form each takes and how often, grouped by what reads it. What a frame is called is a subject of its own: see 4DS Dummy Names.

How to read this

Each entry shows the property, the options it accepts, and then every spelling found in the shipped models with a count. The format is forgiving — case, spaces around commas and braces around tags all vary between models and none of it changes the meaning.

Every object has a User Props box at the bottom of the 4DS panel. Whatever it holds is written back unchanged, so a property this add-on has never heard of still survives a round trip. The format allows 255 bytes; longer text is clipped on export with a warning.

01Switches written into flags

These never reach the game. The exporter reads the word and sets the matching switch on the object, and that switch is what the game acts on. Verified across every model: each one lines up exactly with its flag, in both directions. In Blender you can tick the switch instead of typing the word.

03Collision and detector volumes

Placed on dummies to give an object physical shape. The shape comes from the dummy’s box; the tag says how it is treated. Only DYNB is read by the running game — the rest are consumed when the level’s collision data is built.

The number after the comma is a filter mask deciding what the volume interacts with. It is written as hex (0x13) or plain digits (41), with or without a space, and both spellings appear in the shipped models. The mask is read when the level’s collision data is built rather than by the running game, so the meaning of each bit is not established here — the full set of values used is listed below. A trailing letter code (,S, ,M, ,NFT, ,OFF_) appears on a handful and is also unestablished.
