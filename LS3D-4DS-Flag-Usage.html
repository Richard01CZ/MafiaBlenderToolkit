4DS Flag Usage

Every switch the format carries, counted across the 3,261 models shipped with the game — 100,965 objects, 44,640 materials, 1,132 sectors and 2,739 portals — with the models that use each one.

Reading this

The bar under each count shows how much of that category uses the switch. “Which models” lists the files with the most occurrences, then a few example object names. A switch marked not used exists in the format but appears nowhere in the shipped game — you can still set it, you just have no reference to copy.
